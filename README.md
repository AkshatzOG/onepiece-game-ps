# Draft Battle — Showcase

A portfolio page for **Draft Battle**, a fan-made One Piece crew-drafting game. This repo holds the showcase page only — screenshots, a description, and a link to the live game. It isn't the game's source.

**Live game:** [onepiece-game.pages.dev](https://onepiece-game.pages.dev)
**Showcase page:** open `index.html`, or enable GitHub Pages on this repo to serve it directly.

## What Draft Battle is

A browser game where two crews take turns rolling random One Piece characters and drafting them into roles — Captain, Vice, Tank, three Support — until both sides are full. Each character carries a community-rated power score, so the draft is a real trade-off between banking a strong early pick and holding out for better role coverage. Play against a friend or an AI opponent.

Alongside the draft, the project includes:

- **A community ratings board** — signed-in players vote on character power levels and suggest new additions, reviewed before going live.
- **A live leaderboard** — Google or Discord sign-in saves your best crew, ranked by total power score.
- **A wanted poster generator** — upload a photo, pick a print style, and generate a Marine-issue bounty poster with draggable elements.

## Built with

- HTML / CSS / JavaScript (no framework)
- Supabase — authentication and data
- Cloudflare Pages — hosting and deployment
- Google & Discord OAuth
- html2canvas — client-side image export
